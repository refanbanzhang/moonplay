# Moonplay Web

这是 Moonplay 的本地音频网页版，不需要后端或数据库。网页不会上传音乐文件，音频只在当前浏览器中读取和播放。

## 预览

网页通过 GitHub Pages 自动部署。访问仓库的 Actions 页面查看部署状态和线上地址。

## 使用方式

1. 打开页面，直接进入歌曲列表。
2. 点击右上角 `+`，选择一个或多个音乐文件。
3. 点击播放按钮播放，拖动音量条调节音量。可同时播放多首，每首独立控制音量。
4. 再次点击右上角 `+` 可以继续追加音乐，不会清空已有列表。

音乐文件只保存在当前浏览器的 IndexedDB 中，不会上传。刷新页面后会自动恢复音乐列表；清除网站数据或更换浏览器后需要重新选择音乐。不同浏览器支持的音频格式也可能不同；无法解码的文件会显示为不可播放。

## PWA 与性能

- 应用壳会通过 Service Worker 缓存，首次打开后没有网络也能重新打开页面。
- 本地音频文件不会上传，也不会被 Service Worker 缓存，而是由 IndexedDB 保存；清除网站数据后仍需再次选择音乐。
- 列表节点会复用，播放时不会整列表重绘。
