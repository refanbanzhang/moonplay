# Moonplay Web

这是 Moonplay 的本地音频网页版，不需要后端或数据库。网页不会上传音乐文件，音频只在当前浏览器中读取和播放。

## 预览

网页通过 GitHub Pages 自动部署。访问仓库的 Actions 页面查看部署状态和线上地址。

## 使用方式

1. 点击 `./START`。
2. 选择包含音乐文件的目录。
3. 点击播放按钮播放，拖动进度条跳转，点击音量按钮调节音量。
4. 点击右上角 `+` 可以重新选择目录。

浏览器安全规则不允许网页自动读取固定的本地路径，因此每次打开网页都需要手动选择目录。不同浏览器支持的音频格式也可能不同；无法解码的文件会显示为不可播放。
