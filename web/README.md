# Moonplay Web

这是 Moonplay 的本地音频网页版，不需要后端或数据库。网页不会上传音乐文件，音频只在当前浏览器中读取和播放。

## 启动

在项目根目录执行：

```bash
./scripts/serve-web.sh
```

然后打开 <http://localhost:8080>。

也可以传入其他端口：

```bash
./scripts/serve-web.sh 3000
```

## 局域网访问

服务启动后，在同一个局域网内的设备上访问：

```text
http://本机局域网 IP:8080
```

例如 `http://192.168.1.10:8080`。如果无法访问，请检查 macOS 防火墙是否允许 Python 接收传入连接。

## 使用方式

1. 点击 `./START`。
2. 选择包含音乐文件的目录。
3. 点击播放按钮播放，拖动进度条跳转，点击音量按钮调节音量。
4. 点击右上角 `+` 可以重新选择目录。

浏览器安全规则不允许网页自动读取固定的 macOS 路径，所以每次打开网页都需要手动选择目录。不同浏览器支持的音频格式也可能不同；无法解码的文件会显示为不可播放。
